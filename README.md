# お絵描き伝言

タブレット1台を3〜12人で回して遊ぶ、日本語のお絵描き伝言ゲーム。4〜8人がおすすめです。

公開先： https://learning-apps-jp.github.io/oekaki-dengon/

ソース： https://github.com/learning-apps-jp/oekaki-dengon

## 起動

`index.html`をEdgeやChromeで開くとローカルで遊べます。フォルダ内のファイルをまとめて保持してください。

通常のWebアプリとして確認する場合は、このフォルダで `node serve.cjs` を実行し、`http://127.0.0.1:4176` を開きます。ホームの「オフライン準備完了」が表示された後は、サーバーへの接続なしでも利用できます。Service WorkerはHTTPSまたはlocalhostでのみ有効です。

名前・回答・絵はブラウザ内のIndexedDBに保存され、外部送信されません。ブラウザのデータ削除やプライベート閲覧では再開できなくなる場合があります。進行中1ゲームと直近の完了1ゲームを保存します。

## 遊び方

人数と名前を座っている順に登録し、カテゴリ・ラウンド数・時間を設定します。画面が指定する人に端末を渡し、本人が「始める」を押します。描く人は言葉を絵にし、次の人は絵を言葉で推測します。最後に全員で答え合わせをします。奇数人数では先頭はお題確認のみを行い、次の人から描画します。先頭は毎ラウンド交代します。

文字・数字で絵の答えを示さず、途中の相談や画面の覗き見を控えて遊んでください。採点はありません。

## 構成

- `仕様書.md`：基準となる仕様
- `index.html`、`style.css`、`app.js`：画面・描画・保存・進行
- `core.js`：人数別の担当順と独自のお題160件
- `sw.js`、`manifest.webmanifest`、`icon.svg`：オフライン用キャッシュとアプリ設定
- `verify.cjs`：進行、保存、オフライン、画面サイズの自動検証

公式テレストレーションのアプリではありません。ルールの参考資料は仕様書に記載しています。

## 検証結果（2026年10月1日）

Edge / Chromiumの自動検証で、3〜12人の全人数の1ラウンド、5人で5ラウンドの先頭交代、お題の非重複、空欄防止、描画の戻す／やり直す、画面回転相当のサイズ変更、秘密の受け渡し、下書き復元、保存失敗時の再試行、時間切れ時の空欄防止、オフラインでの再開と新規ゲーム、ローカルファイル起動が通過しました。結果は `verification.json` に保存しています。

iPad SafariとAndroid Chromeの実機、ペンの手のひら誤検知、日本語ソフトウェアキーボードは未検証です。これらは実機での試遊が必要です。
